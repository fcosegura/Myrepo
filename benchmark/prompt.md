# Prompt del benchmark

Texto exacto que se envía a todas las IAs (sin correcciones, sin contexto extra):

```
Genera una comparativa entre el Oppo Watch X2 y el OnePlus Watch 4, genera una tabla que compare las specs y geenra una conclusion en base a ello
```

## Por qué este prompt

Es vago a propósito:

- No pide fuentes, mercado, precio ni fecha.
- Tiene un typo (`geenra`).
- Mezcla dos productos de años distintos (X2 en 2025, Watch 4 en 2026).
- El Watch 4 es muy reciente; los scrapers y bases de datos lo mezclan con el Watch 3 / Watch X2 / Watch X3.

Mide sobre todo: búsqueda actual, no copiar agregadores, y no alucinar lo que falta.
